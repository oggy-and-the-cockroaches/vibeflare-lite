# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

The Shipcheck community takes the security of our platform and user codebases very seriously.

If you believe you have found a security vulnerability in Shipcheck (including the scanner, sandbox manager, or Sentinel RASP runtime), **please do not report it through public GitHub issues.**

Instead, please report it privately:
1. Send an email to `security@shipcheck.dev` (or open a GitHub Private Security Advisory via the **Security** tab).
2. Include details about the vulnerability:
   - Steps to reproduce
   - Potential impact
   - A proof-of-concept (PoC) if available
3. We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure and patch release.
